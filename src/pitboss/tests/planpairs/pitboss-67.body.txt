## Done-when

- `pitboss pressure` appends (time, none|hold) to `[runners] record` and exits 0 only after `[runners] quiet_minutes` (default 15) with no hold; else exit 1 with the minutes remaining, which are minutes only, never a job count (`test_newest_hold_decides`, `test_exactly_the_quiet_period`, `test_lines`, `test_zero_quiet_minutes_with_jobs_waiting`).
- `pitboss queued` appends a hold; `pitboss push` appends one only when its push goes out, nothing when refused, in a dry run, when git fails, or with `--draft` (`test_queued_after_a_clear_look`, `test_refused_push_changes_nothing`, `test_push_that_goes_out`, `test_pushes_that_do_not_record`). A push that went out whose hold could not be written says "push WENT OUT", tells to run `pitboss queued`, and exits 2 (`test_push_went_out_but_the_hold_was_not_recorded`). There was no `pitboss push`, so this adds it: pressure check, `git push`, record; `--draft` skips both; dry run unless `--no-dry-run`.
